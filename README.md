# Festival DevOps 2026 🚀

Este proyecto es una plataforma para la gestión de un festival musical, enfocada en la automatización, contenedorización y buenas prácticas de DevOps.

## 🛠️ Tecnologías Utilizadas
* **Git:** Control de versiones local.
* **GitHub:** Alojamiento del repositorio remoto y colaboración.
* **Docker:** Creación de imágenes y contenedorización de los microservicios.
* **Docker Compose:** Orquestación de los contenedores del festival (Base de datos, Backend, Frontend).

## 🐳 Arquitectura Docker y Docker Compose
El entorno está diseñado para levantarse con un solo comando:
```bash
docker compose up -d
